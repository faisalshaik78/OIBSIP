# Marie Curie Tribute Page — OIBSIP Task 2

A responsive tribute page built with HTML5 and CSS3, featuring a biography, timeline, and quote section.

## Run

Open `index.html` in a modern browser.

## Image source

The page attempts to load a portrait through Wikimedia Commons' Special:FilePath service. If it does not load, replace the image URL with a specific Commons file and add its author, license, and attribution details. Verify the individual file's license before redistribution.

## Features

- Responsive layout
- Contrasting section backgrounds
- Serif display typography and sans-serif body text
- Biography and milestone timeline
