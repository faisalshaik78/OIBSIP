# Oasis Infobyte Internship Projects (OIBSIP)

A collection of beginner-friendly web development projects built with HTML5, CSS3, and vanilla JavaScript as part of my internship task practice.

## Projects

| Task | Project | Technologies | Folder |
|---|---|---|---|
| 1 | Calculator | HTML, CSS Grid, JavaScript | [task-1-calculator](./task-1-calculator/) |
| 2 | Marie Curie Tribute Page | HTML, CSS, responsive design | [task-2-tribute-page](./task-2-tribute-page/) |
| 3 | To-Do Web App | HTML, CSS, JavaScript, localStorage | [task-3-todo-app](./task-3-todo-app/) |
| 4 | Login Authentication Demo | HTML, CSS, JavaScript, localStorage | [task-4-login-authentication](./task-4-login-authentication/) |

## Run locally

1. Download or clone this repository.
2. Open the relevant task folder.
3. Open its `index.html` in a modern browser. No build tools are required.

## Project notes

- The calculator uses vanilla JavaScript event listeners and conditional logic without `eval()`.
- The to-do app stores tasks in the browser's localStorage.
- The authentication task is a **front-end learning demo only**. It is not secure enough for real users or production use because browser storage and client-side logic can be inspected or modified. Production authentication requires a trusted server, secure password hashing, HTTPS, and server-side sessions or tokens.
- The tribute page is dedicated to Marie Curie and includes a link to Wikimedia Commons for image sourcing. Add an appropriately licensed image if desired and retain its attribution/license details.
